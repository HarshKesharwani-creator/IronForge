⚡ IRONFORGE

Forge your ultimate battle plan.
IronForge is a custom, full-stack fitness tracking web application engineered with a minimalist, "Hardcore Iron" aesthetic (deep charcoal and electric neon green). It is designed to capture biometric data, set rigorous fitness protocols, and track gym progress without the fluff.

🛠 Tech Stack

Frontend: HTML5, Vanilla CSS (Custom Design System), JavaScript (ES6+)

Backend: Firebase v10 Web SDK (Modular)

Authentication: Firebase Auth (Secure Manual Email/Password Entry)

Database: Cloud Firestore (NoSQL)

🔥 Core Features

Secure Authentication Hub ([MODULE-02]):
A mobile-first, floating card UI featuring a manual sign-up flow specifically tailored to collect vital demographic data (Name, DOB, Address) without relying on social logins.

Smart Role-Based Routing:
Bulletproof login logic that intercepts authenticated users and routes them dynamically. Standard athletes are sent to the app, while authorized creators are instantly routed to the backend Command Center.

Interactive Profile Onboarding ([MODULE-03]):
A sleek, slide-out wizard intercepting new users post-signup. It captures biometric baselines (Height/Weight), training goals (Hypertrophy, Strength, Fat Loss), and equipment access (Commercial Gym, Home Gym, Bodyweight) before granting dashboard access.

God-Mode Admin Command Center ([MODULE-10]):
A desktop-optimized, highly secure data terminal. Features live fetching of all registered users from Firestore, presented in a searchable, sortable directory with a slide-out "Deep Dive" profile panel for full administrative control.

📐 Design System (The "Hardcore Iron" Aesthetic)

Background: Deep Charcoal (#121212)

Primary Accent: Electric Neon Green (#39FF14)

Typography: Bold, aggressive, high-contrast sans-serif. Clean lines and high legibility.
